A global admin
{{- if .Values.admins }} ({{ join ", " .Values.admins }}){{ end }} creates workspaces with
POST /v1/workspaces and names their members and roles. People use the web app at /app.
{{- if not (include "metis.usesPostgres" .) }}

This release stores workspaces in SQLite with one replica
{{- if .Values.persistence.enabled }} on a volume that `helm uninstall` keeps{{ else }}, in a
temporary directory: everything is lost when the pod goes{{ end }}. For more replicas, set
database.url or database.existingSecret to a PostgreSQL database.
{{- end }}
