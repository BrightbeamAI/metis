# Worker Contestability Record

Workers and reviewers can contest a fragment at any time. Each action is an auditable,
CHAP-recorded event.

- **Fragment id:** ____________________
- **Action:** challenge / correct / withdraw / supersede / request_re_elicitation
- **Raised by:** ____________________
- **Rationale:** ____________________
- **Proposed correction (if any):** ____________________
- **Outcome:** routed to Mission Group / consent withdrawn / re-elicitation requested / superseded

Workers must be able to see records tied to their contribution. Contestability is a right, not an
exception.
